# 👑 The 48 Laws of Power — Interactive Experience

An interactive web experience inspired by Robert Greene's **The 48 Laws of Power**, presenting its core ideas through a dark, immersive interface with historical examples and interactive visualizations.

## ✨ Features

- 📜 Explore all **48 Laws of Power**
- 🔎 Expand each law for explanations, examples & metaphors
- 🏛️ Historical examples featuring figures such as Caesar, Napoleon & Machiavelli
- 🧩 Interactive **Laws Relationship Grid**
- 💭 Wisdom & quote visualization
- 🌙 Dark / Light mode
- ✨ Animated, immersive UI
- 📱 Responsive design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 💡 About the Project

I built this project as an experiment in turning ideas from a book into an interactive digital experience rather than presenting them as static text.

It combines frontend development, UI design, animations, interactive content, and information visualization.
